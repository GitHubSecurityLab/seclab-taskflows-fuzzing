# Support

## How to Get Help

If you need help with this project, here are your options:

### Documentation

- Read the [README.md](./README.md) for installation, usage, and architecture details.
- Check the [CONTRIBUTING.md](./CONTRIBUTING.md) for development setup and coding conventions.

### Issues

- Search [existing issues](../../issues) to see if your question has already been answered.
- If not, open a new issue with a clear description of your problem or question.

### Scope of Support

This project is maintained by the GitHub Security Lab team on a best-effort basis. We will do our best to respond to issues and pull requests in a timely manner, but cannot guarantee specific response times.

### What We Can Help With

- Bug reports and reproducible issues.
- Questions about project architecture and design decisions.
- Guidance on contributing new features or taskflow stages.

### What Is Out of Scope

- General AFL++ or fuzzing methodology questions (please refer to [AFL++ documentation](https://aflplus.plus/docs/)).
- Issues with upstream dependencies (seclab-taskflow-agent, seclab-taskflows).
- Environment-specific setup issues unrelated to the project itself.
